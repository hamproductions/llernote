    Method & caveats

    • Lineup (65): the llfans 出演者 list — μ's 6, Aqours 5, 虹ヶ咲 11 + 侑 (応援出演), Liella! 11 (the data's 1期生〜3期生), 蓮ノ空 11 (the data's 102〜105期生), いきづらい部！ 10, SIM guests 10 (2026 cast).
    • Who sang each song: names in the setlist remark; else the remark's version label (B.G.P., 1〜3期生) through the data's member lists; else the credited artist's members. Dream Believers = 11, アイシイ = 3 (DOLLCHESTRA B.G.P.), 未来予報ハレルヤ! = Liella! 1期生 (5).
    • Weights: full 1 · 1番→ラスサビ-type short ¾ · TV size / short ½ · medley bit ⅓. Movie Edit and Movieサイズ count as full songs (assumed). Hand correction: WE WILL!! (Day 1) counts ¾ — it ran 4:40–7:24 on the stream (1番 + bridge); stored in data/show-overrides.json.
    • Billing: each song goes to its own franchise (the song's series). Songs from several series with no single home (NEXT CARD, 愛♡スクリ～ム!) go to Others. Original type (full group / unit / solo / cross-franchise / guest) comes from the credited artist, not from who performed.
    • Everything is read from the llfans setlists in the llernote data: it matches that data, not necessarily what happened on stage. One show per day is a small sample, so the push check is a hint, not a verdict.
    • Checked by an audit script that rebuilds every song from the raw data, an independent recount, and a page audit across every view (scripts/audit-*.py).
